# PRODIGY_WD_02 — Stopwatch

A browser-based stopwatch with start, pause, reset, and lap timing.

## Features
- Centisecond display
- Start and pause control
- Record and list lap times
- Reset stopwatch and lap list
- Responsive layout

## Run locally
Open `index.html` in a modern browser. No build tools, packages, or credentials are required.

## Files
- `index.html` — stopwatch interface
- `styles.css` — responsive presentation
- `app.js` — timing and lap logic
